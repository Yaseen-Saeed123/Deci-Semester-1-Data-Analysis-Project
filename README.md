# 📋 Final Project Overview Summary

This project is divided into **two main parts**:

---

### 🎲 Part 1: Probability Experiment
* **Task:** Design and run a simple probability experiment (e.g., rolling a die, flipping a coin, spinning a wheel).
* **Process:** Record trials, calculate theoretical vs. experimental probabilities, measure variation, and track how results change as trial counts increase.
* **Core Insight:** Demonstrate that experimental outcomes differ from theoretical expectations, especially with smaller trial sizes.

---

### 📊 Part 2: Dataset Analysis & Visualization
* **Task:** Work with a provided dataset containing student daily-life metrics (study habits, screen time, sleep, attendance, homework completion, and exam performance).
* **Process:** Clean the dataset, generate charts/visualizations, analyze relationships between variables, and extract statistical patterns.
* **Core Insight:** Build a clear data story showing how lifestyle factors relate to academic performance, supported by data evidence.
